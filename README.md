# Hydrotherm

Data center cooling water vs. climate-driven evapotranspiration: a hand-checkable comparison tool, by Dougalien Systems.

Every panel has a "hand calculation" expander that shows the equation with your numbers substituted, so each result can be checked with a calculator. Sources are listed in the app's Method tab.

## Run it on your own computer

```
py -m pip install -r requirements.txt
py -m streamlit run app.py
```
